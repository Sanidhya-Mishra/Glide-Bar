# Design mockups

12 concept directions for the GlideBar hot bar, delivered as an interactive gallery (light/dark aware).
Each concept shows the same three jobs — **search**, **pinned shortcuts**, **system vitals** — in a
different position, emphasis, and style, so you can compare real trade-offs.

## The 12 concepts
1. **Top Notch Pill** — floating rounded pill centered at the top; expands downward on hover.
2. **Right Edge Dock** — vertical dock on the right screen edge; icons + mini stats.
3. **Bottom Floating Dock** — macOS-style centered dock with blur, sitting above the taskbar.
4. **Full-Width Ribbon** — slides down from the top edge, full width, sectioned.
5. **Draggable Card** — compact floating widget card with a drag handle.
6. **Collapsed Sliver** — a thin accent sliver that expands into the full bar on hover.
7. **Glass / Acrylic** — heavy glassmorphism, translucent blur, vibrant accent.
8. **Command Palette** — search-forward, Spotlight-like big field + results.
9. **Stat-First Dashboard** — vitals (ring gauges) lead; search is secondary.
10. **Minimal Mono** — ultra-minimal monochrome, hairline rules, tiny footprint.
11. **Segmented Capsule** — one capsule split into Search | Pins | Stats segments.
12. **Corner Hub** — anchored to a screen corner, compact hub layout.

## How to use
Open the published gallery artifact (link shared in chat), compare the concepts in both themes, and tell me:
- which **position** you want (top / bottom / right edge / floating / corner),
- which **emphasis** (search-first / stats-first / balanced),
- which **style** (glass / minimal-mono / solid-rounded).

You can also mix — e.g. "Right Edge Dock position with the Glass style and Stat-First emphasis." Your pick
drives workstream (E) in [`../AGENTS.md`](../AGENTS.md).
